# Telephone Line 0.1.5

This patch adds the accepted companion cockpit to the existing install tree. `src/install` still copies `src/`, `schemas/`, `docs/`, and `LICENSE`. The cockpit lives under `src/cockpit/` and opens with `Start-TelephoneCockpit.ps1`. It is not a Lead, not a ninth route, and not a replacement for the bundled dashboard.

The shipped default config has empty source paths. Display names come from the caller's files. Packaging still refuses arbitrary binaries; the only exception is `src/cockpit/runtime/win-x64/` `.exe`/`.dll` payload.

The eight routes and existing callback, dashboard, and installation contracts are unchanged. 0.1.4 and its assets remain available.

本补丁把已验收的驾驶舱放进现有安装树。仍用原来的 `src/` 复制，入口是 `src/cockpit/Start-TelephoneCockpit.ps1`。它不是 Lead，不是第九条路线，也不替代自带看板。随包默认配置没有任务来源。八条路线及既有回叫、仪表盘、安装契约保持原状，0.1.4 及其资产保留。
