# Telephone Line 0.1.8

This patch is the accepted cockpit visible-status increment. Public source and download assets are prepared for the repository [Releases](https://github.com/captpascallv-dev/telephone-line/releases) page as tag `v0.1.8`. v0.1.7 and earlier version assets remain available and must not be overwritten.

Visible surfaces use the same lifecycle and partial-delivery facts together. Local-only, public-only, both, or neither is one boolean combination on overall judgment, HUD row, Now, Progress, Blocked, Next, Needs Pascal, and current roles. Exact accepted ownership stays with the original Lead package that was actually accepted; a later preparation, dispatch, or prefix is not that acceptance and is not product delivery. An unhandled current failure stays in front of remaining acceptance: overall, HUD, and Stuck show the failure plus what is still open. Handler prose is not product acceptance and is not painted as normal progress.

The real remaining wait is the final live-window check, which is still incomplete and still requires explicit computer-use resumption. This note does not claim that live-window check is done. It does not claim a new route measurement.

PI and DeepSea v4 remain as previously accepted.
