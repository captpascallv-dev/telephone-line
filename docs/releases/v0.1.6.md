# Telephone Line 0.1.6

This patch makes current roles visible on the default details page. One project still occupies one left-hand row. The right-hand page lists the current owner separately, then each current executor, assigned reviewer, and live army task as its own item. Each item shows a recognizable name, the work, the actual model and effort, the present status, and that item's blocker. Missing identity is shown as not obtained. "No reviewer assigned" appears only when a source says so.

Returned executor work is not owner acceptance. A CLI turn ending is not project completion. A failed item is not hidden by another executor still running. Adopted or replaced rounds stay in history. Model names and effort are ordinary status, not diagnostics. Session ids, raw logs, and the ten technical axes stay behind "Show technical diagnostics".

0.1.5 and its assets remain available.

本补丁让默认详情页能看见当前角色。左侧仍是一个项目一项。右侧单独列出当前负责人，再逐项列出各当前执行者、已安排审核者和仍在进行的军团工作。每项有可识别称呼、所做工作、真实模型和 effort、当下状态和该项阻点。缺身份写未获取。只有来源明确说未安排审核时才写未安排审核。

执行交回不是负责人验收通过。CLI 回合结束不是项目完成。一项失败不能被另一项仍在执行盖住。已采用或被替代的旧轮留在历史。模型和 effort 是普通状态，不藏进技术诊断。会话 ID、原日志和十个技术轴仍在「查看技术诊断」后面。

0.1.5 及其资产保留。
