# Telephone Line 0.1.4

This patch fixes a race between the initial task starter and exact-job relay
recovery. If recovery published a relay owner first, the starter could launch
a second relay and fail while creating `relay-owner.json`, even though the
task and callback completed.

Initial startup now uses the existing relay recovery lock and adopts a live
owner. Genuine initial owner publication errors still propagate. The command
is never replayed by this repair.

The regression runs the actual starter and relay helpers with a deterministic
interleaving. It checks one command, one relay, one callback, durable delivery,
natural process exit, and preservation of a real publication failure.

The eight routes and existing callback, dashboard, and installation contracts
are unchanged. The 0.1.3 release and its assets remain available.

本补丁修复首次启动与同任务 relay 恢复之间的竞争。恢复先写入 owner 时，
首次启动会复用仍存活的 relay；真实写入失败仍会报错。回归覆盖单次命令、
单个 relay、一次回叫、持久化交付和自然退出。八条路线及既有回叫、仪表盘、
安装契约保持原状，0.1.3 及其资产保留。
